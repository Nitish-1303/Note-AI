# Note AI 🧠📓

**Note AI** is an intelligent web application that helps users generate, organize, and summarize notes using state-of-the-art AI language models.  
The platform combines efficient note-taking with AI-powered enhancements to help users capture insights faster and smarter.

This project bridges modern frontend engineering with practical AI integration — perfect for productivity workflows.

---

## 🌟 Project Vision

In today’s fast-paced world, capturing ideas, meeting insights, and research notes can be overwhelming. Note AI was built to:

- Provide a smarter note-taking experience
- Help users produce summaries, insights, and instant clarifications
- Apply AI tools for real productivity use
- Demonstrate frontend + AI integration

This application reflects my interest in applying AI capabilities toward everyday user tools.

## ⚙️ Installation & Setup

### 1. Clone the repository
```bash
git clone https://github.com/Nitish-1303/Note-AI.git
```

### 2. Navigate into the folder
```bash
cd Note-AI
```

### 3. Install dependencies
```bash
npm install
```

### 4. Add your AI API Key
Create a `.env` file and add:
```
VITE_OPENAI_API_KEY=your_api_key_here
```

### 5. Start the development server
```bash
npm run dev
```

The app runs at:

```
http://localhost:5173
```
